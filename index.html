Module 01

First-order time response

A first-order sensor, like a thermometer, has one part that stores energy (the heat capacity of the bulb) and one that resists its flow (the glass wall). Its model:

τ·dy/dt + y = K·x(t)G(s) = K / (τs + 1)

K (static sensitivity) decides where the output ends up. τ (time constant) decides how fast it gets there.

Module 02

First-order frequency response

A sinusoid through a first-order sensor

A first-order sensor filters high frequencies. Move a slider to see the output sine become smaller and lag further behind its input.

G(s) = K / (τs + 1)M = 1 / √(1 + (ωτ)²)φ = −atan(ωτ)

The displayed amplitude ratio M compares the actual output with the ideal output K·x(t). The phase is negative for a lagging output.

Frequency controls

Validation example: τ = 0.2 s, x(t) = sin(2t), M ≈ 0.93, phase lag ≈ 21.8°.

Input and output sines

Dotted black: input · dashed grey: ideal Kx · orange: sensor output (steady state).

Live frequency response

Bode plot: magnitude and phase

Cutoff at ωc = 1/τ: amplitude drops to −3.01 dB and phase is −45°. The dot tracks the selected frequency.

Dynamic-error calculator

The course defines the fractional dynamic error as δ = M − 1, which is negative for attenuation. The error magnitude is (1 − M) × 100%.

At fmax = 100 Hz, a ≤ 5% amplitude error requires τ ≤ √(1/0.95² − 1)/(2π·100).

Module 03

Second-order response & state space

Mass–spring–damper sensor

The damping ratio ζ controls oscillation and overshoot; natural frequency ωn controls the time scale. Parameters of the physical model are synchronized with the normalized model.

G(s) = ωₙ² / (s² + 2ζωₙs + ωₙ²)m·ẍ + b·ẋ + k·x = F(t)
ωₙ = √(k/m)ζ = b / (2√(mk))

Live model controls

Or adjust physical parameters. Both sets remain synchronized.

The plot shows displacement x for force step F. Steady displacement xss = F/k. Normalized response x/xss enables comparison across different springs.

Second-order step response

Orange: current · purple dashed: underdamped · gold dashed: critical · grey dashed: overdamped.

Response metrics (read from sampled curve)

Rise time is the first 10%→90% crossing interval; settling time uses a ±2% band. Peak time and overshoot are only defined when there is a peak above the steady state.

Poles in the s-plane

State-space matrices & eigenvalues

ẋ = Ax + BF,   y = Cx + DF

x₁ = displacement, x₂ = velocity, C = [1, 0], D = 0.

Eigenvalues of A must equal the transfer-function poles.

State trajectory: phase plane (x₁ vs x₂)

For an underdamped sensor, displacement and velocity spiral toward equilibrium (F/k, 0); for an overdamped sensor, the trajectory returns without oscillating.

Module 04

Guess the sensor

A hidden sensor responds to an input, with a little noise. Read the curve and work backwards, the way an engineer does with a real sensor. Submit your estimate and the page reveals the true values, overlays the true curve on your guess, and scores you.

    Hidden sensor

    Hover over the dots to read values. Drag to zoom, double-click to reset.

    Reveal

    ParameterTrueYour guessErrorPoints

    Green line = true response · red dashed = your guess · dots = what you were shown.

    Methods you can use

    • First order, step: K is the final value divided by the step size (1). τ is the time at which the output reaches 63.2% of its final value. Or plot ln(error fraction) against t: it is a line with slope −1/τ.
    • First order, sine: once the transient has died out, measure the amplitude ratio M = 1/√(1+(ωτ)²) or the phase lag φ = tan⁻¹(ωτ).
    • Second order, step: read the overshoot and the peak time. The overshoot gives ζ, then the peak time gives ωₙ. Solve in this order:
      Mp = (peak − final) / final ζ = −ln Mp / √(π² + ln²Mp) ωₙ = π / (tp·√(1−ζ²))
      Here Mp is the overshoot as a fraction (30% means 0.30) and tp is the time of the first peak, in seconds.

    Scoring

    Each parameter is scored by relative error. Within 10% earns full marks. Between 10% and 50% the score falls linearly, and beyond 50% it is zero. A round is worth 100 points, split equally across its parameters.
